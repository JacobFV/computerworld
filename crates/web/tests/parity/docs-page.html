The Au type

An Au is an app unit: one sixty-fourth of a CSS pixel, stored in a signed 32-bit integer. Every position and size in the layout engine is an Au, so the same document lays out to the same coordinates on every platform, with no floating-point unit in the loop.

Note
The representable range is about ±33 million pixels. Layout saturates at the ends of that range rather than wrapping, so an absurd document produces an absurd but finite box.

Construction

Au::from_px(px: i32) -> Au

Converts a whole number of pixels. This is the constructor most callers want; it cannot fail and it cannot round.

use fixedpoint::Au;

let margin = Au::from_px(16);
let half = Au::from_px(16).scale(1, 2);
assert_eq!(half.to_px_round(), 8);
Au::from_f64_px(px: f64) -> Au

Converts a fractional pixel value. It is intended for parsing literal CSS numbers only; layout code should never see an f64. The value is rounded half away from zero to the nearest app unit.

Passing a value computed by floating-point arithmetic defeats the point of the type: two platforms can disagree in the last bit and therefore in the last app unit. Parse the decimal string instead.

Arithmetic

The usual operators are implemented and all of them saturate:

  • +, -, unary -
  • * and / by an i32
  • scale(num, den), which multiplies before dividing so that scale(1, 3) of Au::from_px(1) keeps its precision
    • the intermediate is a 64-bit integer
    • the result is rounded half away from zero
  • percent_of(p), where p is in hundredths of a percent

Ordering and comparison

  1. Two values compare as their underlying integers.
  2. min, max and clamp are provided as methods.
  3. There is no NaN; every value is ordered.

Rounding

to_px_round()
The nearest whole pixel, halves rounded away from zero. This is what paint uses to snap borders.
to_px_floor()
The whole pixel at or below the value.
to_px_ceil()
The whole pixel at or above the value. Scroll extents use this so that the last row is never cut off.
to_f64_px()
The exact value as a float, for serialisation only.
Round late, round once, and write down which way you rounded.

Parameters of scale

NameTypeDescription
numi32The numerator. May be negative.
deni32The denominator. A zero denominator yields zero rather than a panic.

Errors

None of the operations return a Result. Overflow saturates, division by zero yields zero and conversions from out-of-range floats clamp. This is the right behaviour for a layout engine, where a wrong number is better than no frame, but it means the caller must check inputs that come from outside.

let big = Au::from_px(i32::MAX / 64);
assert_eq!(big + big, Au::MAX);   // saturates
assert_eq!(big / 0, Au::ZERO);    // no panic
