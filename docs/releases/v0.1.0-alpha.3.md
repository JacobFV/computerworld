# v0.1.0-alpha.3

The third prerelease of Computerworld. Its machines now run programs: two real
language interpreters in the shell, a debugger behind VS Code's Run and Debug, a
filesystem with owners and modes that bite, professional applications on exact
engines, and phones whose every gesture is the one the device has. Python represents
this version as `0.1.0a3` under PEP 440. The full list of changes is in the
[changelog](../../CHANGELOG.md#010-alpha3--2026-09-18).

## What is new since v0.1.0-alpha.2

- **Programs run.** `python3` and `node` are real interpreters over the machine's
  VFS, network and entropy: sockets and HTTP, child processes through the shell,
  Python threads on a deterministic scheduler, Node `worker_threads` with
  `SharedArrayBuffer` and `Atomics`, ECMA-402 and `zoneinfo` from recorded CLDR/ICU,
  a byte-exact `zlib`, and a REPL for each.
- **A debugger.** Breakpoints with conditions, hit counts and logpoints, stepping,
  call stacks, scopes, watches and evaluation, behind a DAP-shaped seam — driven from
  Visual Studio Code's Run and Debug view on all three desktops.
- **Professional applications.** Visual Studio Code, FreeCAD on an exact B-rep kernel
  with STEP AP214/AP242, KiCad with an interactive router and circuit simulation,
  video editors over one engine, image editors on a layered raster engine, and
  spreadsheets and databases on real XLSX/ODS and SQLite-compatible engines.
- **A filesystem that behaves like one.** Modes, owners, groups, link counts, inodes
  and three timestamps; `umask`, `chmod`, `chown` and permission checks that fail
  reads; real `tar`, `gzip`, `zip` and `rsync` bytes; a trash the file managers use.
- **A shell that refuses rather than ignores.** POSIX `awk`, a full `sed`, `xargs`
  and the text utilities, and one contract: an unimplemented flag is refused by name
  with status 2 instead of being silently dropped.
- **Text and phones.** Hebrew, Arabic, Thai, Devanagari, CJK and emoji render with
  shaping and bidi, with the CJK/emoji font pack fetched on demand; iOS home pages,
  the App Library and the home indicator's gestures, Android's navigation bar, drawer
  and Recents, and live scrolling with inertia.
- **A project site.** Five machines running live in the visitor's browser, at
  `site/`, deployed by GitHub Actions.

## Install a pinned version

Use the assets on the [GitHub prerelease](https://github.com/JacobFV/computerworld/releases/tag/v0.1.0-alpha.3).
Select a Python wheel compatible with your platform, or a Wasm bundle for browser
and Node use. Wheel targets are Linux x86_64 (manylinux2014), macOS arm64 and
Windows x86_64, using CPython 3.9+ abi3; only successfully built and tested platforms
are uploaded, and the asset list is authoritative. See [Python](../python.md) and
[JavaScript/Wasm](../wasm.md). There is no PyPI, npm or crates.io publication.

For source:

```sh
git clone --branch v0.1.0-alpha.3 --depth 1 https://github.com/JacobFV/computerworld.git
```

Rust consumers can pin the Git tag:

```toml
[dependencies]
computerworld = { git = "https://github.com/JacobFV/computerworld.git", tag = "v0.1.0-alpha.3" }
```

## Compatibility and limitations

This is an alpha for technical early adopters. Public APIs, world schemas, action
families, observations, renderer output and snapshot serialization may change.
Checkpoints from earlier alphas are rejected on restore; keep the engine version,
world definition, seed and action sequence together. Pixel output changed across
every desktop scene, and the shell now refuses flag spellings that earlier releases
accepted and ignored — a script that relied on one gets a status 2 and a message
naming the flag.

The browser bundle is about 10.2 MB gzipped, up from 4.9 MB: two language
interpreters, a CAD kernel, an EDA suite, a video engine, a database and a
compressor are in it. The CJK and emoji font pack is fetched on demand rather than
embedded.

The OS views are synthetic, not vendor operating systems or pixel-perfect replicas.
The interpreters are conformant subsets, not CPython and V8: they are checked
against real interpreters program by program, and what they do not implement they
refuse by name. There is no microphone or camera, so voice input, dictation and
Google Lens are announced disabled. Arbitrary native binaries, arbitrary HTML/JS,
native mobile SDKs and a full TCP/IP implementation remain out of scope. See
[desktop fidelity](../desktop-gui.md#rendering-and-fidelity),
[the shell matrix](../shell.md), [debugging](../debugging.md),
[computer semantics](../computers.md) and [security boundaries](../security.md).

## Verification and provenance

Release publication follows [the release process](../releasing.md): the release
workflow builds and smoke-tests each wheel in a clean environment, runs the packaged
Node binding and the archived browser demo offline, and runs the desktop interaction
suites. Checksums identify the downloadable files; the Git tag identifies their
source. Bundled project, font, icon and wallpaper notices accompany the artifacts;
their licenses are independent of the simulator's MIT license.
