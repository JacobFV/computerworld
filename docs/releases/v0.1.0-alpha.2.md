# v0.1.0-alpha.2

The second prerelease of Computerworld, and the first whose binaries carry the
interactive desktop: five OS shells, native applications and a browsable simulated
web, all driven by the same pointer, keyboard and application actions an agent uses.
Python represents this version as `0.1.0a2` under PEP 440. The full list of changes
is in the [changelog](../../CHANGELOG.md#010-alpha2--2026-09-18).

## What is new since v0.1.0-alpha.1

- **A real desktop.** macOS, Windows 11, Ubuntu, iOS and Android shells with a window
  manager (move, resize, snap, minimize, maximize, stacking), click-to-select and
  double-click-to-open on desktops, single taps and gestures on phones, a tabbed file
  manager, launchers, search, notification and control centres, device switches,
  virtual desktops, bookmarks, downloads, screenshots, sharing and the trash. Every
  painted control either does what it says or is announced disabled with a reason.
- **Native applications.** Calendar, Mail, Messages, Docs, Notes, Contacts,
  Settings, Calculator, Clock, Photos, Music, Maps and Weather, each backed by a
  world service or the machine's own files.
- **Editors and menus.** Word wrap in Notepad, TextEdit and GNOME Text Editor, real
  File/Edit/View and primary menus, Up/Down arrows, and a published caret that sits
  on the row actually painted.
- **A simulated web.** Independent sites under realistic domains (search engines,
  mail, docs, drive, video, social, news, shopping, banking, maps, chat assistants
  and more) with responsive layout that reflows at phone width, and per-site browser
  zoom.
- **Shell and terminal.** Truthful exit codes, a prompt and echoed commands with
  `[exit N]` markers, `find` predicates, and many more commands and flags, documented
  in a conformance-tested matrix ([shell](../shell.md)).
- **Perception.** Accessibility-shaped scene views, focus and caret geometry,
  occlusion, whole-pane text buffers with wrap markers, content-derived change
  detection and a per-action `effect` summary.
- **Smaller download.** The browser bundle is about 4.9 MB gzipped (was 13.8 MB).

## Install a pinned version

Use the assets on the [GitHub prerelease](https://github.com/JacobFV/computerworld/releases/tag/v0.1.0-alpha.2).
Select a Python wheel compatible with your platform, or a Wasm bundle for browser
and Node use. Wheel targets are Linux x86_64 (manylinux2014), macOS arm64 and
Windows x86_64, using CPython 3.9+ abi3; only successfully built and tested platforms
are uploaded, and the asset list is authoritative. See [Python](../python.md) and
[JavaScript/Wasm](../wasm.md). There is no PyPI, npm or crates.io publication.

For source:

```sh
git clone --branch v0.1.0-alpha.2 --depth 1 https://github.com/JacobFV/computerworld.git
```

Rust consumers can pin the Git tag:

```toml
[dependencies]
computerworld = { git = "https://github.com/JacobFV/computerworld.git", tag = "v0.1.0-alpha.2" }
```

## Compatibility and limitations

This is an alpha for technical early adopters. Public APIs, world schemas, action
families, observations, renderer output and snapshot serialization may change.
Checkpoints from `v0.1.0-alpha.1` are rejected on restore; keep the engine version,
world definition, seed and action sequence together. Pixel output of every desktop
scene changed.

The OS views are synthetic, not vendor operating systems or pixel-perfect replicas.
Bundled fonts are subset: Hebrew, Arabic, Thai and CJK text draws as hollow boxes.
There is no microphone or camera, so voice input, dictation and Google Lens are
announced disabled. Arbitrary native binaries, arbitrary HTML/JS, native mobile SDKs
and a full TCP/IP implementation remain out of scope. See
[desktop fidelity](../desktop-gui.md#rendering-and-fidelity),
[computer semantics](../computers.md) and [security boundaries](../security.md).

## Verification and provenance

Release publication follows [the release process](../releasing.md): the release
workflow builds and smoke-tests each wheel in a clean environment, runs the packaged
Node binding and the archived browser demo offline, and runs the desktop interaction
suites. Checksums identify the downloadable files; the Git tag identifies their
source. Bundled project, font, icon and wallpaper notices accompany the artifacts;
their licenses are independent of the simulator's MIT license.
