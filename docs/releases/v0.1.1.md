# v0.1.1

The engine is 0.1.0's. What changed is where it installs and where it is explained. The
full list is in the [changelog](../../CHANGELOG.md#011--2026-09-19).

- **Two more wheels.** Linux arm64 (manylinux2014) and macOS x86-64 join Linux x86-64,
  macOS arm64 and Windows x64 on PyPI, so `pip install computerworld` works on arm64
  Linux servers and Intel Macs. The release gate now requires all five wheel platforms
  and Node/Wasm to report the same state and pixel hashes.
- **npm by trusted publisher.** The package is published with the workflow's OIDC
  identity, as PyPI already was. No token exists anywhere.
- **A documentation site.** https://jacobfv.github.io/computerworld/docs/ has the guides
  in reading order, a walkthrough front page, and the Python, JavaScript and Rust API
  references. The README is rewritten around why a researcher would use this and a
  sixty-second example.

Snapshots name the engine that wrote them, so 0.1.0 snapshots are rejected by 0.1.1 and
state hashes differ for the same run. Pin the version with your episode records.
