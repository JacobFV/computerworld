# v0.1.0

The first release of ComputerWorld on the registries: `pip install computerworld` and
`npm install computerworld` now work. The engine is the one `v0.1.0-alpha.3` shipped a
day earlier — machines that run real Python and JavaScript, a debugger behind VS Code, a
filesystem with owners and modes, professional applications on exact engines, phones
with their own gestures — with one fix on top of it and a new way of being released.
Python and Cargo spell this version the same way: `0.1.0`. The full list of changes is
in the [changelog](../../CHANGELOG.md#010--2026-09-19).

## What is new since v0.1.0-alpha.3

- **PyPI.** Wheels for Linux x86-64 (manylinux2014), macOS arm64 and Windows x64,
  CPython 3.9+ abi3. There is no source distribution; other platforms build from source.
- **npm.** One `computerworld` package for Node and the browser. Node resolves it to the
  CommonJS binding, bundlers and browsers to the ES module, and both load the single
  Wasm beside them. It carries the reference world, the font pack and the notices, and
  is published with a provenance attestation.
- **The release is a logged run.** `.github/workflows/publish.yml` builds and verifies
  the candidates, requires Linux, macOS, Windows and Node/Wasm to report the same state
  and pixel hashes, creates this release with its `SHA256SUMS`, and then publishes to
  each registry the files it downloaded back from this release and checked against
  those sums. Nothing is uploaded from a laptop, and PyPI holds no token: it trusts
  this workflow by OIDC.
- **Slack and Discord are readable.** Their skins named the sidebar's colour as the
  page's surface, so Slack drew its dark message text on dark purple. Cards and forms
  now sit on the page.
- **The project site** is a slideshow of thirty-nine scenes, each a machine driven from
  a fresh boot to something mid-work by the actions an agent would send — and two
  phones in one conversation.

## Install

```sh
pip install computerworld==0.1.0
npm install computerworld@0.1.0
```

The same files are assets of the
[GitHub release](https://github.com/JacobFV/computerworld/releases/tag/v0.1.0), with
the standalone Wasm bundles and the static browser demo. See [Python](../python.md) and
[JavaScript/Wasm](../wasm.md).

**crates.io is not published.** The workspace is fifty-one crates with path
dependencies, and the renderer embeds about 38 MB of fonts and wallpapers against a
10 MB limit per crate. Rust consumers pin the tag:

```toml
[dependencies]
computerworld = { git = "https://github.com/JacobFV/computerworld.git", tag = "v0.1.0" }
```

## Compatibility and limitations

This is a 0.x release, not a stability promise. Public APIs, world schemas, action
families, observations, renderer output and snapshot serialization may change between
minor versions; keep the engine version, world definition, seed and action sequence
together. A snapshot names the exact engine that wrote it, so snapshots from
`v0.1.0-alpha.3` are rejected on restore, and state hashes — which cover the engine
version — differ from alpha.3's for the same run; replay the actions instead. Pages of
the Slack- and Discord-skinned chat services also render differently, so pixel hashes
of those pages change.

The browser bundle is about 10.2 MB gzipped. The CJK and emoji font pack is fetched on
demand rather than embedded; the npm package includes it under `fonts/`.

The OS views are synthetic, not vendor operating systems or pixel-perfect replicas.
The interpreters are conformant subsets, not CPython and V8: they are checked against
real interpreters program by program, and what they do not implement they refuse by
name. There is no microphone or camera. Arbitrary native binaries, arbitrary HTML/JS,
native mobile SDKs and a full TCP/IP implementation remain out of scope. See
[desktop fidelity](../desktop-gui.md#rendering-and-fidelity),
[the shell matrix](../shell.md), [debugging](../debugging.md),
[computer semantics](../computers.md) and [security boundaries](../security.md).

## Verification and provenance

This release was made by [the release process](../releasing.md), and the run that made
it is public under the repository's Actions tab (`publish`). The workflow builds and
smoke-tests each wheel in a clean environment, installs the npm package into an empty
project and runs a machine from it, runs the packaged Node binding and the archived
browser demo offline, and runs the desktop interaction suites. `SHA256SUMS` identifies
the downloadable files, the Git tag identifies their source, and
`cross-platform-parity.json` records the hashes the four builds agreed on. Bundled
project, font, icon and wallpaper notices accompany the artifacts; their licenses are
independent of the simulator's MIT license.
