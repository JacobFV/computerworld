# v0.1.2

The machine draws its pointer, the internet grows, and the apps stop pretending. The
full list is in the [changelog](../../CHANGELOG.md#012--2026-09-19).

- **The pointer is drawn.** Every desktop frame carries the machine's own mouse pointer,
  shaped for what is under it, and the site and browser demo hide the host cursor over
  a desktop.
- **The debugger follows the frame you pick.** Each stopped frame carries its own scopes,
  and hovering an identifier while stopped shows its value.
- **FreeCAD grows up.** Additive and subtractive primitives, PartDesign Booleans, datums,
  expressions, and CAD and EDA files that open from the file manager.
- **Machines that have been used.** Each desktop in `company-2026` starts with an
  engineer's parts, projects, packages, notes and scripts.
- **Messages, Slack and Discord are their own services.** Texting with receipts and
  tapbacks; Slack with threads, reactions and unread counts; Discord with roles and
  channels. Slack and GitHub render like themselves.
- **The internet grows.** Maps draw a map, forty more sites with `www.` and `m.` aliases,
  `https://` on every service, error pages for unreachable hosts and 404s, and a page
  format that can express real interfaces.

Package and engine version are both `0.1.2`; snapshots from earlier versions are
rejected, as every version's are.
